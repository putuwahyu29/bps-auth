# Kebijakan Keamanan

Jika Anda menemukan celah keamanan dalam paket ini, mohon untuk tidak membuka issue publik di GitHub.

Silakan laporkan temuan secara tertutup melalui [GitHub Security Advisories](https://github.com/putuwahyu29/bps-auth/security/advisories) atau hubungi [@putuwahyu29](https://github.com/putuwahyu29).

### Informasi Laporan
Saat melaporkan kerentanan, sertakan:
1. Deskripsi celah keamanan dan potensi risikonya.
2. Langkah-langkah untuk mereproduksi masalah (Proof of Concept).
3. Versi paket, PHP, dan Laravel yang terdampak.
4. Usulan perbaikan (jika ada).
